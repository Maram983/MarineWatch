# MarineWatch

A marine conservation platform designed to connect pollution reporting, environmental monitoring, and community cleanup activities across Saudi Arabia.

## Overview

MarineWatch brings divers, volunteers, and administrators together through a focused digital experience:

- Divers can document marine pollution with location details and evidence.
- Volunteers can discover and join cleanup activities.
- Administrators can review reports and monitor marine conditions.
- Interactive map views help surface environmental activity and affected areas.

## Highlights

- Role-based experiences for divers, volunteers, and administrators
- Pollution reporting workflow with evidence upload and location capture
- Interactive marine monitoring map
- Activity discovery and volunteer participation
- Dashboard views for reporting and operational oversight
- Responsive interface across public and authenticated pages

## Built With

- HTML, CSS, and JavaScript
- Bootstrap
- Node.js and Express
- Supabase
- Leaflet maps
